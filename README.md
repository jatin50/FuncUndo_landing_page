# FuncUndo Landing Page 2 (Fibery Edition)

The official, witty, anti-corporate landing page and documentation site for [FuncUndo](https://github.com/ChronosTeamx/FuncUndo), an opinionated function-level version control extension for Visual Studio Code.

Inspired directly by the playful, earthy, and uncorporate product aesthetic of [Fibery.io](https://fibery.com/).

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons:** Lucide React
- **Features:** 
  - Dynamic dual view: **Interactive Scalpel Landing View** & **Full Sarcastic Docs View**
  - Interactive Scalpel Sandbox with tilted hand-written sticky notes and physical `Ctrl+Alt+Z` (or `Cmd+Alt+Z`) key listener
  - "The 3 Horrors of Modern Undoing" (The Steamroller, The Stash Black Hole, The Zombie Comment-Out)
  - Full collapsible sidebar documentation covering:
    - *Philosophical Rants* (What is FuncUndo?, Why FuncUndo?, FuncUndo vs Git & The World, The Scalpel Manifesto)
    - *The Nerd Engine* (WebAssembly Tree-sitter Worker, Relational Blast Radius Graph, SQLite WASM)
    - *Survival Guide* (Keybindings, Function Resurrection, Retention & Vacuum Settings)

## Development

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
